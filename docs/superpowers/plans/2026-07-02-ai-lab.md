# AI LAB — 자율 전략 리서치 플로우 (자비스 루프)

날짜: 2026-07-02
카테고리: 트레이딩 (Sidebar → 트레이딩)

## 목표
정적 대시보드 아님. **AI가 실제로 작동하는** 리서치 루프를 보여주는 살아있는 UI.
플로우: **자체생각(THINK) → 검토(REVIEW) → 집행(EXECUTE) → 학습(LEARN).**

## 정직성 원칙 (핵심)
- LEARN 지식패널 = **실제 experiment_registry** 리플레이(TSMOM 엣지, buyback 엣지, momentum/wave/funding REJECT). 진짜 축적 지식.
- 큐 가설 검토 = **진짜 random-baseline 수학**(`random_same_frequency` + `empirical_p_value` + WF 2분할). 데이터는 합성이면 `synthetic_demo` 배지로 명시.
- CB/BW 오버행 해소 = 큐에 넣되 audit이 **BLOCKED_BY_DATA**(linkage/잔액 파이프 미구축) 반환 — 실제 데이터 게이트 그대로 노출.
- **가드레일:** EXECUTE는 절대 live 매매 안 함. verdict 분류 + registry 기록(LEARN)까지만. PASS여도 `paper_candidate (human gate)` 표시. paper→live는 사람.

## 백엔드 (`research/lab/`)
- `hypotheses.py` — Hypothesis 스펙 + SEED_QUEUE(CB/BW 2종 + 합성 데모). 지식 = registry에서 런타임 로드.
- `evaluator.py` — 3분기: precomputed(registry 리플레이) / data-blocked / quick synthetic(진짜 수학).
- `pipeline.py` — LabEngine: 4스테이지 상태머신 + 백그라운드 스레드 + 이벤트 링버퍼 + threading.Lock. snapshot() → API.
- `api_server/lab_api.py` — `GET /lab/state`, `POST /lab/run`, `POST /lab/autopilot`. main.py include.

## 프론트 (`app/lab/page.tsx`)
- 헤더 + 펄스 라이브 배지. 4스테이지 브레인 플로우(활성 글로우/ping). 스트리밍 터미널 로그. 현재 가설 카드(메트릭 채워짐). verdict 피드(색상). 큐. 컨트롤(다음 실행 / 오토파일럿+가드레일 문구).
- 폴링 ~700ms. 디자인 토큰만. lib/api.ts 함수. AbortController.
- Sidebar 트레이딩 그룹에 `AI LAB` 추가.

## 테스트 (`tests/test_lab_pipeline.py`)
합성 가설 통과/REJECT, BLOCKED_BY_DATA, registry 리플레이, next-open 진입, 상장폐지 미드롭, 비용 스트레스 감소, snapshot 스키마, live 미실행 가드.
